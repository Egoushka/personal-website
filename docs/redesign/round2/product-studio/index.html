.github/workflows/agent-ready.ymlplanned
name: agent-ready
on: [deployment_status]
jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - uses: egoushka/agent-ready-action@v1   # free, no key
        with:
          url: ${{ github.event.deployment_status.environment_url }}
          fail-on: llms-txt, mcp-discovery

Runs after every deploy and fails the job when a door you care about closes. Free. The action name is a plan, not a published package.
