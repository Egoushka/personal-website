Agent-ready checker

Scans a URL for what an AI agent looks for: WebMCP, MCP, x402 and llms.txt.

Paste an address and see which agent doors the site has open, which are missing, and what each one would take. Runs as a web page, as a GitHub Action on every deploy, and as an API an agent can call and pay for per check.

        with:
          url: ${{ github.event.deployment_status.environment_url }}
          fail-on: llms-txt, mcp-discovery

WebMCP for ASP.NET and Blazor

Lets a .NET web app expose its actions to an agent in the browser, from attributes on code you already have.

Mark a page action or a minimal-API endpoint and it shows up as a WebMCP tool the visitor's agent can call, with the schema generated from your C# types.

planned API
// Pages/Orders.razor.cs
[WebMcpTool("find_order", Description = "Find an order by number")]
public Order? Find(string number) => _orders.Find(number);
{ "name": "find_order",
  "description": "Find an order by number",
  "inputSchema": { "type": "object",
    "properties": { "number": { "type": "string" } },
    "required": ["number"] } }

touchstone

Runs the same queries on SQL Server and on PostgreSQL and shows where the answers differ.

A migration that compiles can still answer differently: trailing spaces, collation, rounding, NULL ordering. touchstone replays your queries on both and lists every row that changed.

real behaviour
